What I Built

งานนี้คือเว็บไซต์ Portfolioที่รวบรวมข้อมูลแนะนำตัว รายละเอียดของงาน วิธีการพัฒนาและสิ่งที่ได้เรียนรู้

เปิดเว็บไซต์จากเครื่องตัวเอง มี Client หรือ Server เกิดขึ้นแล้วหรือไม่

มี Clientเกิดขึ้นแล้วแต่ยังไม่มี Web Server เพราะเมื่อเปิดไฟล์ HTML จากเครื่องโดยตรง Browser ทำหน้าที่เป็น Client ที่อ่านไฟล์จากระบบไฟล์ของเครื่อง แล้วแปลผล HTML และ CSS เพื่อแสดงหน้าเว็บให้ผู้ใช้เห็น

How I Built It

Development Steps

  1. วางแผนโครงสร้างเว็บไซต์และลำดับเนื้อหา
  2. สร้างไฟล์ index.html และโครงสร้าง HTML พื้นฐาน
  3. สร้างไฟล์ style.css และเชื่อมด้วย link rel="stylesheet"
